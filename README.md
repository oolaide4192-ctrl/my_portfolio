## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/samad-source/Damilare.git
   ```

2. Open the project folder:

   ```bash
   cd Damilare
   ```

3. Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.
